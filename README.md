# QAVault — UAT Test Management System

**Portfolio Project | Chantel Hlongwane**

A functional UAT Test Management tool built to demonstrate business analysis, application support, and quality assurance skills.

## 🧰 Built With

- HTML5, CSS3, Vanilla JavaScript
- LocalStorage for data persistence
- Zero dependencies — works offline

## ✅ Features

- Add, edit, and delete test cases with full detail (steps, expected result, actual result)
- Track status: Pending → In Progress → Pass / Fail / Blocked
- Log defects against failed test cases with severity rating
- Live UAT progress bar showing pass/fail/blocked/pending breakdown
- Filter by module, priority, and status
- Sidebar navigation with live counts per status and module

## 📋 Use Case

Mirrors real-world UAT processes used in functional application support environments — particularly relevant to government enterprise systems like IFASS and CALMIS where structured testing and defect tracking are critical to successful deployments.
